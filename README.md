# 💀 Am I Cooked? Detector

> **"If you're asking whether you're cooked... you're probably already cooked." 🗿**

## Features

* 🔍 Detects the type of situation using keywords
* 🔥 Generates a Cooked Level from 40%–100%
* 😂 Multiple funny responses for every category
* 🎲 Random roast selection
* 🤔 Handles unknown situations
* 💀 Different cooked statuses
* 🐍 Built completely with Python
* 📦 No external packages required

---

## Technologies Used

* Python 3
* `random` module
* Lists
* Dictionaries
* Loops
* Conditions
* String handling

---

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/spideyverse-creator/Am-I-Cooked-Detector.git
```

### 2. Open the project

```bash
cd Am-I-Cooked-Detector
```

### 3. Run the program

```bash
python main.py
```

That's it! 🎉

No `pip install` is required.

# Unknown Situations

If the program doesn't recognize the situation, it randomly chooses one of these:

* I don't understand what happened... BUT YOU ARE STILL COOKED 💀
* Situation unclear. Your future is also unclear. 🗿
* Bro entered a situation even Python can't understand 😭
* No category found. Maximum confusion detected.
* Whatever happened... it probably wasn't a good idea 💀
* Python has no idea what you're talking about. Neither do we.
* This situation is beyond scientific explanation 😭
